# Contributing to Awesome AI Marketing & Sales Tools

Thank you for your interest in contributing to the **Awesome AI Marketing & Sales Tools** list!

## 📋 Guidelines for Inclusion

To maintain high quality, submitted tools must meet the following criteria:

1. **Target Focus:** The tool must have a clear, demonstrable application in digital marketing, SEO, content, advertising, B2B outbound sales, CRM, or marketing automation.
2. **Live Product:** The tool must be an active, operational service (not just a waitlist page or concept pitch).
3. **Transparent Pricing:** The product must have a published pricing page or an explicit enterprise quote contact.
4. **Independent Audit:** All entries will be cross-verified and indexed on [Toolvern.com](https://toolvern.com).

## 🚀 How to Submit

### Option 1: Fast-Track Editorial Submission (Instant)
Submit your tool via the official web form at [https://toolvern.com/submit/](https://toolvern.com/submit/). Verified submissions are automatically synchronized to this repository during catalog releases.

### Option 2: GitHub Pull Request
1. Fork this repository.
2. Add your tool to the appropriate category in `README.md` in alphabetical order:
   ```markdown
   - **[ToolName](https://yourwebsite.com)** `Pricing model` — Short one-sentence value proposition.
   ```
3. Submit a Pull Request with a clear description and link to your live product.
